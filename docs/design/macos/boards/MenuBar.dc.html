Standard order. App, File, Edit, View, then the custom Session and Server menus, then Window and Help, as the HIG orders menu bar menus.

Shortcuts. Main menus show them and context menus don’t. Every shortcut uses Command, so Control combinations keep reaching the terminal. Restart ⌘R and Stop ⌘. follow Xcode’s Run and Stop.

Availability. Main menus dim commands the selection can’t run, such as Send EOF for a PTY. Context menus hide them. Restart… reads Start… when the run is stopped.

Kit styling. Rows are 24 pt of SF Pro 13 in a 12 pt-radius glass menu. Items are plain text, as in the kit’s Edit menu, and only the system’s own Dictation and Emoji items carry symbols.
