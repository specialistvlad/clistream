## Reproduce a failed check

Run `make test e2e` for Go and CLI coverage and `make test-deployment` for the four-container deployment. On a Mac, run `make apple` once. Set `SIMULATOR_ID` to the iPhone or iPad simulator and run `apple/test-device.sh`. Use `apple/test-device.sh macOS` on a Mac desktop. Each suite starts its own broker, devices and child processes. The script prints a new result directory and checks the actual workspace files separately from XCTest.

To isolate a failing scenario set `CLISTREAM_TEST_SUITES` to `hosted`, `files`, `terminal` or, on iOS, `touch` or `scroll`. On Xcode 27 with iOS 27, the `voiceover` case enables the simulator’s screen reader, which can speak through the Mac’s speakers, then restores its previous setting. Pass space-separated names to run several suites. The iPad terminal suite uses AXe to send a hardware keyboard chord to the simulator and waits for byte 0x04 at the child. Set `CLISTREAM_APP_DRIVERS=1` to include the installed model clients. The four-client harness and live-provider options are documented in the [verification record](../verification.md).
