## Reproduce a failed check

Run `make test e2e` for Go and CLI coverage and `make test-deployment` for the four-container deployment. The hosted Apple matrix runs all UI suites on isolated Macs. To reproduce a case on a dedicated CI runner, run `make apple` once. Set `SIMULATOR_ID` to the iPhone or iPad simulator and run `apple/test-device.sh`. Use `apple/test-device.sh macOS` for the native Mac app on that runner. Each suite starts its own broker, devices and child processes. The Go fixture launches real peers and exports TCP and UDP echo services. The test checks both through the forwarded loopback addresses.

For an individual XCTest, run its Xcode scheme through `go run ./scripts/apple-ui xcodebuild` with the simulator destination and `-only-testing` identifier. The VoiceOver case enables the simulator’s screen reader and restores the previous setting. The iPad terminal suite uses AXe to send a hardware keyboard chord and verifies byte 0x04 at the child. The optional model-provider case requires external driver sessions. See the [verification record](../verification.md) for multi-client runs and outstanding checks.
